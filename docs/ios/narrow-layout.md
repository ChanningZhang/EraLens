# 窄屏时间轴适配

2026-09-27，基于现有 iOS 离线应用增加可用宽度与泳道密度适配。

## 行为

- 按内容容器宽度判断布局，600px 及以下使用窄屏模式，适用于手机、iPad 窄窗口和窄屏 Web。
- 王朝栏展开时取容器宽度的 20%，限制在 72–88px；左上角按钮可折叠至 12px。宽窗口恢复 102px 王朝栏，回到窄窗口保留折叠偏好。
- 窄屏默认紧凑泳道：普通卡片高度 36px，上下各留 4px，普通泳道合计 44px；舒适模式为 40px + 上下各 6px，合计 52px。并立、共同在位和悬挂称谓继续沿用现有布局规则并计算实际高度。
- 卡片常规名字由 15px 调整到 13px，文字换行依据真实卡片宽高计算，悬挂称谓保留空间；卡片宽度始终服从在位时间和时间缩放。
- 窄屏搜索移到独立的 56px 顶部工具栏，输入字号 16px；王朝栏开关、设置与地图按钮保留 44px 触控区域。标尺高度缩至 60px。
- 显示设置可选择紧凑泳道，或恢复按屏幕自动调整。布局偏好通过已有 PlatformSettings 保存，原生使用 Preferences，Web 使用 localStorage。
- 王朝栏、卡片投影、标尺、泳道分组框、命运线端点和地图裁剪共用同一份布局参数。折叠、密度切换和窗口变化保留中心年代与时间缩放。
- 工具栏避开 safe area，修复 iPad 状态栏及手机横屏与品牌栏的重叠。

## 验证

- Web 与 shared TypeScript 检查、iOS Web 构建和 Simulator 原生构建通过。
- 新增窄屏布局用例 4 项通过：折叠与宽窗口恢复、普通/并立/缺载卡片及命运线几何一致、悬挂称谓空间、泳道分组框宽度。
- iPhone 17 Pro / iOS 26.4 已检查竖屏、横屏、折叠、设置面板和重启后的折叠偏好；iPad A16 / iOS 26.4 已检查宽屏和状态栏安全区域。
- 全量 Web 测试 117 通过、9 失败；shared 测试 193 通过、23 失败。用 HEAD 中修改前的相关实现复制到 `.build/narrow-baseline/` 复跑，失败项与数量一致，属于已有测试问题。
- 尚未在真机上验收动态字体与 iPad Split View；320px 和边界宽度已通过布局计算检查。
